## 题目信息

- **平台**：BugkuCTF
- **题目**：富强民主
- **类型**：MISC
- **分值**：15
- **描述**：一长串“公正富强和谐…”的价值观词语

## 解题思路

题目描述是典型的**社会主义核心价值观编码**：12 个词（富强、民主、文明、和谐、自由、平等、公正、法治、爱国、敬业、诚信、友善）对应 0-11 的“数字”。

## 解题过程

1. 把描述按词切分，每两个汉字映射为词序号（0-11）：

   ```python
   values = ["富强","民主","文明","和谐","自由","平等","公正","法治","爱国","敬业","诚信","友善"]
   desc = "公正公正公正诚信文明公正民主公正法治法治友善平等和谐敬业和谐富强和谐富强和谐文明和谐平等公正公正和谐法治公正公正公正文明和谐民主和谐敬业和谐平等和谐敬业和谐敬业和谐和谐和谐公正法治友善法治"
   nums = []
   i = 0
   while i < len(desc):
       for idx, v in enumerate(values):
           if desc.startswith(v, i):
               nums.append(idx); i += 2; break
   ```

2. 按特殊规则展开数字序列：
   - 普通数字直接保留；
   - 遇到 10：值 = 10 + 下一位；
   - 遇到 11：值 = 下一位 + 6。

3. 展开后的数字两两一组，每两个数字组成一个十六进制字节，转 ASCII：

   ```python
   digits = []
   i = 0
   while i < len(nums):
       a = nums[i]
       if a == 10: digits.append(10 + nums[i+1]); i += 2
       elif a == 11: digits.append(nums[i+1] + 6); i += 2
       else: digits.append(a); i += 1
   out = bytes(digits[j]*16 + digits[j+1] for j in range(0, len(digits), 2))
   print(out)  # b'flag{90025f7fb1959936}'
   ```

## 知识点总结

- **价值观编码**：12 个词 → 0-11 的数字，本质是“把十六进制字符换成中文词”。
- **边界处理**：10/11 需要借位展开，直接按普通映射会乱码。
- **编码识别**：看到一长串固定中文词，优先怀疑价值观编码。

## 反思

一开始我用“每两个数字拼十进制”的思路解，结果全是乱码；后来按评论提示改成“10 加下一位、11 下一位加 6”才正确。做编码题要先看输入字符集，再找规则。
