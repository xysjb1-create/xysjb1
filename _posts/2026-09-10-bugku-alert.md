- **描述**：flag0
- **目标地址**：`http://160.202.254.160:18861`

## 解题思路

打开页面后，浏览器弹出一个对话框，内容为“flag就在这里”，但并没有直接显示 flag。

这类题目通常需要查看页面源代码，寻找被隐藏或编码的内容。

## 解题过程

1. 按 `Ctrl+U` 查看网页源代码。
2. 在源代码中搜索 `flag`，发现一行 HTML 注释：

   ```html
   <!-- &#102;&#108;&#97;&#103;&#123;&#50;&#53;&#49;&#54;&#49;&#100;&#49;&#50;&#50;&#57;&#50;&#98;&#52;&#53;&#57;&#49;&#97;&#49;&#55;&#102;&#97;&#55;&#55;&#102;&#53;&#53;&#97;&#54;&#101;&#51;&#54;&#101;&#125; -->
   ```

3. 这是一串 **HTML 十进制字符实体编码**，每个 `&#数字;` 对应一个 ASCII 字符。
4. 使用在线工具或浏览器控制台解码，得到真正的 flag。例如在控制台执行：

   ```javascript
   '&#102;&#108;&#97;&#103;&#123;&#50;&#53;&#49;&#54;&#49;&#100;&#49;&#50;&#50;&#57;&#50;&#98;&#52;&#53;&#57;&#49;&#97;&#49;&#55;&#102;&#97;&#55;&#55;&#102;&#53;&#53;&#97;&#54;&#101;&#51;&#54;&#101;&#125;'
     .replace(/&#(\d+);/g, (_, n) => String.fromCharCode(n));
   ```

## 知识点总结

- **HTML 实体编码**：`&#xx;` 表示十进制 ASCII 码，常用于在页面中隐藏文本。
- **源码审计**：查看源代码仍是 Web 题最基础的信息搜集手段。
- **编码识别**：看到连续的 `&#数字;`，应立刻想到 HTML 实体编码，可以写一行 JavaScript 快速解码。
