## 题目信息

- **平台**：BugkuCTF
- **题目**：头等舱
- **类型**：Web
- **分值**：15
- **描述**：头等舱
- **目标地址**：`http://160.202.254.160:15207`

## 解题思路

页面只显示“什么也没有。”，没有其他内容。题目名为“头等舱”，强烈暗示与 **HTTP 头部（Headers）** 有关：信息可能藏在 HTTP 响应头中，而不是页面正文里。

## 解题过程

1. 按 `F12` 打开开发者工具，切换到 **Network（网络）** 面板。
2. 按 `F5` 刷新页面，点击第一个请求（通常是当前页面地址）。
3. 在右侧选择 **Headers（标头）** 选项卡。
4. 向下滚动到 **Response Headers（响应头）** 区域。
5. 发现一个自定义头字段：

   ```
   Flag: f1ag{784a0311b5f9a60ea977123653a3159}
   ```

6. 复制该值，提交即可。

## 关键代码

```
Flag: f1ag{784a0311b5f9a60ea977123653a3159}
```

## Flag

```
f1ag{784a0311b5f9a60ea977123653a3159}
```

> 注意：前缀是 `f1ag`（数字 1），不是 `flag`。

## 知识点总结

- **HTTP 响应头**：服务器可以在响应头中返回自定义字段，常被用来隐藏 flag。
- **Network 面板**：开发者工具中查看请求/响应头的核心工具。
- **信息泄露**：页面无内容时，应检查头部、Cookie、状态码等。
