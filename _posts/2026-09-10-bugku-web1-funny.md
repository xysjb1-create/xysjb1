## 题目信息

- **平台**：BugkuCTF
- **题目**：WEB1（滑稽）
- **类型**：Web
- **分值**：10
- **描述**：flag①
- **目标地址**：`http://160.202.254.160:11052`

## 解题思路

题目只给了一个“滑稽”的页面，没有其他明显提示。对于这类 Web 题，第一步通常是 **查看页面源代码**，检查是否有注释、隐藏元素或敏感信息。

## 解题过程

1. 打开题目地址，页面显示一张滑稽表情和验证码输入框。
2. 右键点击页面，选择 **“查看网页源代码”**（或按 `Ctrl+U`）。
3. 在源代码中搜索关键词 `flag`，很快在 `<body>` 标签之后发现一行 HTML 注释：

```html
<!-- flag{7c83efd3b5a5d8f02dd18718be0622fa} -->
```

4. 复制注释中的内容，回到题目页面提交。

## Flag

```
flag{7c83efd3b5a5d8f02dd18718be0622fa}
```

## 知识点总结

- **源码审计**：查看网页源代码是 Web 题最基础、也最常用的信息搜集手段。
- **HTML 注释**：`<!-- ... -->` 中的内容不会渲染到页面上，但会原样出现在源码中。
- **查看源代码 vs 检查元素**：注释在“查看源代码”里能看到，但在开发者工具的 Elements 面板（渲染后的 DOM）里不一定保留，所以找注释要优先用 `Ctrl+U`。
