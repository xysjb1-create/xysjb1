## 题目信息



- **平台**：BugkuCTF

- **题目**：ok

- **类型**：Crypto



## 解题思路



题目名“ok”提示 Ook!——Brainfuck 的“猩猩皮”变体，所有指令由 `Ook.`、`Ook?`、`Ook!` 三个词组成。



## 解题过程



1. 把题目密文粘贴到在线 Ook! 解码器（如 splitbrain.org/services/ook）。

2. 解码器先还原为 Brainfuck，再执行输出明文。

3. 或者手动按映射表还原：



   ```

   Ook. Ook?  = >

   Ook? Ook.  = <

   Ook. Ook.  = +

   Ook! Ook!  = -

   Ook! Ook.  = .

   Ook. Ook!  = ,

   Ook! Ook?  = [

   Ook? Ook!  = ]

   ```



4. 输出中即为 flag，提交。



## Flag



```

flag{***}  # 以实际输出为准

```



## 知识点总结



- **Ook!**：2001 年设计的 Brainfuck 变体，全部指令都用“Ook+标点”表示。

- **家族关系**：Brainfuck → Ook! → Short Ook!（.!?），认出一个就认识全家。



## 复盘



和上一题 `[+-<>]` 是同一个家族，只是换了“皮”。做这类题先看字符集：全是 Ook 词就是 Ook!，全是 .!? 就是 Short Ook!。
