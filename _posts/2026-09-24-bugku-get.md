## 题目信息

- **平台**：BugkuCTF
- **题目**：GET
- **类型**：Web
- **分值**：10
- **描述**：无
- **目标地址**：`http://160.202.254.160:11209`

## 解题思路

题目给出了一段 PHP 源码：

```php
$what=$_GET['what'];
echo $what;
if($what=='flag')
    echo 'flag{***}';
```

代码通过 `$_GET['what']` 接收 URL 参数，如果参数值等于 `flag`，就会输出真正的 flag。因此，我们需要在 URL 中传入 `?what=flag`。

## 解题过程

1. 访问目标地址：

   ```
   http://160.202.254.160:11209
   ```

2. 在 URL 后添加 GET 参数：

   ```
   http://160.202.254.160:11209/?what=flag
   ```

3. 页面回显 `flag` 以及真正的 flag 字符串：

   ```
   flagflag{d1a2e956489d5c4a2babd8689b31ef51}
   ```

4. 提取其中的 flag 并提交。

## 关键代码

$what=$_GET['what'];

## Flag

```
flag{d1a2e956489d5c4a2babd8689b31ef51}
```

> 注：页面回显可能因字体显示为圆括号，提交时以平台实际接受的格式为准。

## 知识点总结

- **HTTP GET 请求**：参数通过 URL 的 `?key=value` 形式传递。
- **PHP `$_GET`**：用于接收 GET 参数。
- **URL 构造**：直接修改地址栏即可发送 GET 请求。
